JellyTV es un cliente de Jellyfin para Apple TV. Se conecta a un servidor Jellyfin que vos indicás —el tuyo o el de quien te dé acceso— y reproduce desde ahí tu propia biblioteca. No requiere crear una cuenta con la desarrolladora, no muestra publicidad y no usa herramientas de analítica de terceros.

Conexión con tu servidor

Esta es la diferencia importante con el resto de las aplicaciones: JellyTV sí se comunica por red, siempre y únicamente con el servidor que vos elegís.

Para iniciar sesión, la aplicación envía el usuario y la contraseña que escribís a la dirección de servidor que indicaste. A partir de ahí pide las bibliotecas y reproduce el video desde ese mismo servidor.

La desarrolladora no opera ese servidor, no lo elige y no tiene acceso a él ni a lo que registre. Lo que ese servidor haga con tus datos —incluido tu historial de reproducción— depende de quién lo administre y de sus propias políticas. Si el servidor no usa una conexión cifrada, los datos viajan sin cifrar por tu red.

Datos que guarda la aplicación

JellyTV guarda en el dispositivo lo necesario para no pedirte los datos en cada uso:

  • la dirección del servidor que indicaste;
  • tu identificador de usuario en ese servidor;
  • un token de acceso emitido por ese servidor;
  • un identificador de dispositivo generado por la aplicación, que el servidor usa para reconocer esta instalación.

Tu contraseña no se guarda: se usa una única vez para obtener el token. Nada de esto se envía a servidores de la desarrolladora.

Permisos

JellyTV no pide acceso a fotos, contactos ni ubicación. Necesita acceso a la red para poder hablar con el servidor que configuraste.
